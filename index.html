Mengapa Belajar TJKT?

Membangun fondasi kuat untuk karier di bidang Network Engineer, System Administrator, Cyber Security, dan IT Support.

Perakitan & Hardware

Memahami arsitektur komputer, komponen utama PC/Server, K3LH, serta teknik troubleshooting perangkat keras secara presisi.

Jaringan & Routing

Konfigurasi IP Address, Subnetting VLSM, Switching, Router MikroTik & Cisco, hingga pengelolaan trafik data LAN/WAN.

Telekomunikasi & Fiber

Pengenalan media transmisi nirkabel, sistem gelombang radio, dan teknik penyambungan kabel Fiber Optic (Splicing).

Administrasi Server

Instalasi dan konfigurasi sistem operasi server (Linux/Windows Server), DNS, DHCP, Web Server (Nginx/Apache), dan FTP.

Keamanan Jaringan

Implementasi Firewall, Filtering IP, VPN (PPTP/L2TP/OpenVPN), Port Security, dan pencegahan serangan siber dasar.

Teknologi Wireless

Perancangan jaringan nirkabel, Access Point, Wireless Distribution System (WDS), dan optimasi sinyal indoor/outdoor.

Cloud Computing

Konsep komputasi awan, virtualisasi (Proxmox/VMware), pemahaman IaaS, PaaS, SaaS, serta pengelolaan infrastruktur Cloud modern.

Teknologi VoIP

Pembangunan sistem komunikasi suara berbasis IP, konfigurasi Server PBX (Asterisk/Elastix), Softphone, dan IP Phone.

Monitoring & Manajemen

Pengawasan performa trafik jaringan dan server menggunakan tools monitoring seperti Zabbix, Cacti, Wireshark, dan Dude.

Alur Pembelajaran TJKT

Peta jalan kompetensi dari tingkat dasar hingga keahlian profesional.

TAHAP 01

Dasar Komputer & K3LH

Pengenalan komponen hardware, instalasi sistem operasi, dan pemahaman K3LH di laboratorium IT.

TAHAP 02

Jaringan Dasar & Kabel

Praktik perakitan kabel UTP/STP (crimping RJ45), pengenalan topologi, serta konsep dasar TCP/IP.

TAHAP 03

Administrasi & Routing

Konfigurasi router/switch, manajemen bandwidth, penyambungan Fiber Optic, dan pengelolaan server.

TAHAP 04

Keamanan & Server Lanjut

Penerapan Firewall, VPN, Virtualisasi Server, Layanan Cloud, dan hardening keamanan infrastruktur.

Sering Ditanyakan

Pertanyaan umum seputar jurusan Teknik Jaringan Komputer & Telekomunikasi.

Apa itu Jurusan TJKT?
TJKT (Teknik Jaringan Komputer dan Telekomunikasi) adalah program keahlian yang fokus pada penguasaan teknologi jaringan, infrastruktur internet, administrasi server, dan sistem telekomunikasi.
Prospek kerja apa saja yang bisa diraih?
Lulusan TJKT dapat berkarier sebagai Network Engineer, Network Administrator, System Administrator, IT Support Specialist, Technician Fiber Optic, hingga Cyber Security Analyst.
Apakah TJKT juga mempelajari tentang keamanan siber?
Ya, TJKT mempelajari konsep dasar hingga menengah terkait keamanan siber, termasuk pengkonfigurasian firewall, enkripsi data, manajemen hak akses, dan manajemen jaringan VPN.
